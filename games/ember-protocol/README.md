# Ember Protocol

一款支持房间链接联机的浏览器肉鸽游戏。

## 在线游玩

部署完成后访问：

<https://panxie45-coder.github.io/>

创建房间后，把游戏生成的房间链接发给朋友，对方打开链接即可加入。

## 0.10.0 更新

- 堡垒型“绝对屏障”最多持续 5 秒，技能冷却不低于 7 秒，避免后期无限无敌。
- 新增近战“裂锋型”和重力控场“星渊型”，包含独立机甲、无人机、弹丸、三条专属升级和终极大招。
- 每 3 波出现“裂界泰坦”BOSS，拥有三阶段弹幕和全队共享的专属核心掉落。
- 商店价格随波次上涨；升级刷新每次最多 2 次、商店刷新每次最多 3 次，且连续刷新逐次涨价。
- 联机同步新增职业技能、BOSS状态、核心掉落和双方独立刷新消费。

## 0.9.1 更新

- 修复单人及多人全队死亡后“再次点火”无法移动、不会继续刷怪的问题。
- 补充六台机甲的终极大招介绍，并在战斗大招栏持续显示简要效果。
- 放大波次和金币信息，在商店、升级界面显示当前生命值。
- 指挥官追踪导弹只在前 0.75 秒制导，之后直线飞行；同时降低后期远程伤害成长。

## 本地开发

需要 Node.js 22：

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布 GitHub Pages。

## 新机甲内容规范

后续增加任何新机甲时，必须作为完整职业套装交付：

- 机甲主体延续现有写实硬表面、透明背景、俯视战斗机甲风格，轮廓和主色必须与已有职业明显区分。
- 同步制作该职业的专属无人机、普通弹丸、主动技能特效和终极大招特效，子弹必须从对应机甲或无人机的实际位置发射。
- 同步加入独立碰撞半径、基础属性、主动/被动技能、终极大招，以及至少三项只属于该职业的特异升级路线。
- 联机协议必须同步新职业的战斗状态；经验与波次共享，个人升级、金币消费和终极能量保持独立。
