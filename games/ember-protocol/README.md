# Ember Protocol

一款支持房间链接联机的浏览器肉鸽游戏。

## 在线游玩

部署完成后访问：

<https://panxie45-coder.github.io/>

创建房间后，把游戏生成的房间链接发给朋友，对方打开链接即可加入。

## 0.13.1 更新

- BOSS 改为随机袋轮换：每个循环会将七位 BOSS 随机洗牌，已经出现过的 BOSS 会从当前循环移除，保证七位各出现一次后才开始下一轮随机。
- 新循环会重新洗牌，并避免循环交界处立即连续出现同一个 BOSS；联机模式只由权威队长抽取并同步结果。

## 0.13.0 更新

- 新增雷霆型、天隼型、熔炉型三台机甲，分别围绕连锁麻痹、轨道狙击、范围灼烧构筑；每台均配有独立机体、无人机、弹丸、主动技能、终极大招和专属升级路线。
- BOSS 阵容由 4 位扩充至 7 位：吞星利维坦会冲锋并发射追踪鱼雷，镜界仲裁者使用对称棱晶弹幕，时蚀守望者通过多层时钟地雷封锁走位。
- 三位新 BOSS 均拥有独立三阶段节奏、本体模型、弹丸模型和战斗特效，并加入每 3 波轮换序列。
- 熔炉型新增持续灼烧状态，雷霆型新增独立电击麻痹状态；两种状态会在敌人身上显示不同动态效果，并由权威主机同步给联机队友。

## 0.12.3 更新

- 每次升级的候选强化由 3 个增加为 4 个；职业专属强化、稀有度权重和满级移出奖池规则保持不变。
- 桌面端升级面板扩展为四列，中等宽度使用 2×2 布局，手机端保持单列滚动选择。

## 0.12.2 更新

- 商店刷新费改为非线性波次价格，并参考玩家当前金币设定最低费用；同一次商店内连续刷新会按更高倍率逐次涨价。
- 商品价格会随波次持续非线性增长，并根据个人钱包与配件强度设置价格下限，后期数千金币不再让商店失去消耗压力。
- 商店配件由 8 种扩充至 21 种，分为补给、武装、防御、核心四类；每次商店会从四类中各提供一件，并优先避开上一批商品。
- 商店道具新增普通、稀有、史诗、传说四档稀有度；高级配件需要在后续波次解锁，且出现权重更低、价格倍率更高。
- 新增量子瞄准镜、磁轨膛芯、复联装填器、自适应机壳、闪避推进器、蜂群超频芯片、职业校准模组和终极增幅核心等差异化效果。

## 0.12.1 更新

- 升级选项新增普通、稀有、史诗、传说四档稀有度与加权概率；终极强化不再每次保底，强力机制越稀有越难出现。
- 有次数或数值上限的终极机制强化达到上限后会直接移出升级奖池，刷新也不会再次抽到；终极伤害强化仍可无限成长。
- 前期敌人构成改为以疾行者和爬行体为主，炮击者、精英与其他特殊敌人会按各自解锁时间在中后期逐步增加。
- 前期敌人上限和刷新速度提高；战斗会周期性触发成批兽潮，后期每批数量、场上容量和敌人生命值持续增长。
- 寒霜技能改为两段控制：命中时敌人完全冻结、停止移动和攻击，冰封结束后仍会保留一段减速；敌人身上会显示动态冰壳和冰晶。

## 0.12.0 更新

## 本地开发

需要 Node.js 22：

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布 GitHub Pages。

## 新机甲内容规范

后续增加任何新机甲时，必须作为完整职业套装交付：

- 机甲主体延续现有写实硬表面、透明背景、俯视战斗机甲风格，轮廓和主色必须与已有职业明显区分。
- 同步制作该职业的专属无人机、普通弹丸、主动技能特效和终极大招特效，子弹必须从对应机甲或无人机的实际位置发射。
- 同步加入独立碰撞半径、基础属性、主动/被动技能、终极大招，以及至少三项只属于该职业的特异升级路线。
- 联机协议必须同步新职业的战斗状态；经验与波次共享，个人升级、金币消费和终极能量保持独立。

## 新敌人内容规范

- 新增远程敌人时，必须同时交付敌人本体、攻击逻辑和独立弹丸/导弹模型。
- 新增近战敌人时，不强行配备导弹；必须同步交付专属挥砍、冲击、突进或碰撞轨迹，并使用贴身伤害判定。
- 新增 BOSS 时，必须提供独立本体模型、阶段机制和与攻击方式相符的弹丸或近战特效，不能直接复用普通敌人的圆点弹丸。
